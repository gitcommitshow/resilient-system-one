# System One spec changelog

Protocol versions are independent of client package versions.

## 1.0.0-draft (2026-10-02)

Initial public draft.

The wire format follows the public System One HTTP API: `POST /v1/systemone` and `GET /v1/models`, with `noul`, `choice`, and `score` questions. This draft is not a copy of any provider's OpenAPI file.

Open questions are listed at the end of [spec.md](spec.md). They are unresolved on purpose.
